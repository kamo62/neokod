# Symphony element inventory, 22 October 2026

This appendix accompanies [Sol’s adjudication](REVIEW-ELEMENTS-2026-10-22.md). It contains 158 existing element/control families across all five prototype pages, including conditional views. Repeated rows, icons, options and graph nodes are grouped by behaviour. Each family has a user job, a disposition and a reason. Sol checked and completed the onboard Opus inventory; the [unaltered consultation](../../research/evidence/recon-2026-10-21/symphony-element-review-2026-10-22/opus-result.txt) preserves the reviewer’s wording separately.

This is a source/design inventory, not 158 executed browser tests. The main report separates rendered checks from source-only conditional controls and names outstanding core/runtime proof. Review IDs D1–D7 and S1–S6 refer to this consultation; F1–F10 refer to the preceding flow review. They feed the canonical plan, not a new work queue.

“Prototype-only” means useful for exploring or explaining a simulated artifact, with no equivalent production control. “Defer” preserves the desired UI direction until an actual runtime contract supplies its data. Ordinary Code-thread managed children remain outside every Symphony surface here.

Dispositions are Keep, Move, Combine, Remove or Defer. "Prototype-only" means the element exists for the demo and has no product counterpart.
